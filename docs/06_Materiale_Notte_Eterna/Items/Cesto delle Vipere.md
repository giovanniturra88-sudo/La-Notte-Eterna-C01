# Cesto delle Vipere

**_Tier 1_** _Oggetto_

Una volta per riposo breve, puoi aprire il cesto e scagliare vipere evocate entro gittata Molto Vicina. Una creatura interessata deve reagire con Agilità: se fallisce, subisce +d6 danni da veleno oppure diventa Vulnerabile fino alla fine del suo turno successivo.

- **Usi:** 1
- **Ricarica:** Riposo breve
- **Costo:** 1 Speranza
