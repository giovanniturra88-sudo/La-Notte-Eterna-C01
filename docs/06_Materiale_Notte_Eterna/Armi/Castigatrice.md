# Castigatrice

**_Tier 3_** _Arma_

### Tratto dell'arma

**_Giudizio Supremo:_** Una volta per scena, quando attacchi un nemico che ha ferito un tuo alleato dal tuo turno precedente, puoi spendere 1 Speranza per ottenere Vantaggio sul tiro. Se colpisci, puoi aggiungere +d6 danni oppure ridurre di un grado la conseguenza subita dal primo alleato che interviene.
