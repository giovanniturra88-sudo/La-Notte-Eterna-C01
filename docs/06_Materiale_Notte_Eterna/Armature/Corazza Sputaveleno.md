# Corazza Sputaveleno

**_Tier 3_** _Armatura_

- **Soglie di Danno:** 11 / 27

### Tratto dell'armatura

**_Ritorsione Tossica:_** Una volta per scena, quando un nemico entro gittata Mischia ti infligge danni, puoi spendere 1 Punteggio di Armatura. L'attaccante subisce +d6 danni da veleno oppure diventa Vulnerabile fino alla fine del suo turno successivo.
