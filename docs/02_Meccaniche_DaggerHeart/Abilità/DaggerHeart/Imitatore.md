**_Livello 9_** _[[Grazia]] Spell._ **_Recall Cost_** _3._

Una volta per riposo lungo, questa carta può imitare le caratteristiche di un'altra carta di dominio di livello 8 o inferiore nella mano di un altro giocatore. **Spendi Speranza pari alla metà del livello della carta** per ottenere l'accesso alla caratteristica. Durata fino al prossimo riposo o finché non spostano la carta nella loro cripta.
