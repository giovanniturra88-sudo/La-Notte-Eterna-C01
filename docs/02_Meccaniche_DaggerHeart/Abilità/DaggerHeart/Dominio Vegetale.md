Effettua un **Tiro Incantesimo (18)**. Una volta per riposo lungo in caso di successo, puoi ridisegnare il mondo naturale, modificando la vegetazione circostante in qualsiasi punto entro la tua portata Lontana. Per esempio, puoi far crescere alberi istantaneamente, aprire un sentiero attraverso rami fitti o creare una parete di radici.
