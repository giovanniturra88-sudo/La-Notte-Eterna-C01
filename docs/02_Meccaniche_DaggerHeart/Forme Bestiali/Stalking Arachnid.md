# Aracnide in Agguato

**_Rango 1_** _(Tarantola, Ragno Lupo, ecc.)_

- **Bonus di Tratto:** Astuzia +1
- **Bonus di Evasione:** Evasione +2
- **Attacco:** Mischia Astuzia d6+1 fisici
- **Vantaggi:** attaccare, arrampicarsi, intrufolarsi

### CARATTERISTICHE

**_Morso Velenoso:_** Quando ottieni successo su un attacco contro un bersaglio entro portata di mischia, il bersaglio diventa temporaneamente _Avvelenato_. Una creatura _Avvelenata_ subisce **1d10** danni fisici diretti ogni volta che agisce.

**_Lancia-Ragnatele:_** Puoi creare un materiale di ragnatela resistente, utile sia per le avventure sia per la battaglia. La ragnatela è abbastanza resistente da sostenere una creatura. Puoi _Trattenere_ temporaneamente un bersaglio entro portata Ravvicinata riuscendo in un Tiro di Astuzia contro di esso.
