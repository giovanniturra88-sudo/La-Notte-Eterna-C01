# Ferita

Danno segnato sul personaggio. Vedi Soglie di Danno: si segnano 1, 2 o 3 PF in base alle soglie (sotto la Maggiore → 1 PF, dalla Maggiore → 2 PF, dalla Grave → 3 PF).
