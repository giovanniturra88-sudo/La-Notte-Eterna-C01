# Pipeweed

Quando scegli la mossa di tempo libero Elimina Stress durante un riposo breve, puoi fumare questa foglia non inebriante per eliminare uno Stress aggiuntivo. Qualsiasi altro PG che ha scelto la mossa di tempo libero Elimina Stress ottiene anche questo beneficio.
