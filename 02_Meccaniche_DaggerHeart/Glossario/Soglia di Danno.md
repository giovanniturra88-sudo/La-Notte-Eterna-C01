# Soglia di Danno

Valori che determinano quanti Punti Ferita si segnano subendo danni: se il danno finale è pari o superiore alla soglia Grave si segnano 3 PF; se è pari o superiore alla Maggiore ma sotto la Grave, 2 PF; se è sotto la Maggiore, 1 PF (danno ridotto a 0 o meno → nessun PF). Le soglie dell'armatura (Maggiore/Grave) si sommano sempre al livello; la soglia "Minore" usata nella Vault (≈ metà della Maggiore) è una convenzione di casa coerente con la scala 1/2/3. Le soglie scalano per rango.
