# Lucertola Possente

**_Tier 3_** _(Alligatore, Coccodrillo, Mostro di Gila, ecc.)_

- **Bonus di Tratto:** Istinto +2
- **Bonus di Evasione:** Evasione +1
- **Attacco:** Mischia Istinto d10+7 fisici
- **Vantaggi:** attaccare, intrufolarsi, rintracciare

### CARATTERISTICHE

**_Difesa Fisica:_** Ottieni un bonus di +3 alle tue soglie di danno.

**_Morso a Scatto:_** Quando ottieni successo su un attacco contro un bersaglio entro portata di mischia, puoi **spendere una Speranza** per bloccare quell'avversario tra le tue fauci, rendendolo temporaneamente _Trattenuto_ e _Vulnerabile._
